# Gate Runner

Gate Runner is a 3D survival platformer for Android in landscape. A robot dodges falling hazards, collects coins and shoots its way through three levels to defeat a boss.

## Controls

- Joystick: move
- Jump: jump
- Fire: shoot
- II: pause

## How to open

1. Clone this repository.
2. Open the folder in Unity 6000.6.0f1 or newer using Unity Hub.
3. Open `Assets/Scenes/Main Menu.unity` and press Play.
