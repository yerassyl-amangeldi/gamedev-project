# DECISIONS

## Неделя 10 — Три типа врагов

- Попросил ИИ помочь с тремя врагами: Patroller, Shooter, Charger. Состояния (FSM) для каждого придумал сам.
- Оставил одно общее зрение `EnemyVision` (дистанция + угол + Raycast) для всех трёх врагов, вместо копии кода в каждом скрипте.
- Враги не берут тег `Enemy`, иначе `Movement` перезапускает уровень от одного касания. Вместо этого они бьют через `Health.TakeDamage`.
- Стрелок стреляет, только если его видно на экране (`rend.isVisible`), чтобы не было атак из-за экрана.
